02 / SUBMISSION

提交一条可核验的记录

下载模板是开始；模板中的 null 表示尚未测量。

明确实验身份

给出代码仓库、完整 commit SHA、测量日期，以及数据版本、切分和候选集合规则。

保留逐轮与逐 seed 数据

至少 3 个独立随机种子，包含第 0 轮与至少 1 个更新轮次。逐 seed 数值与汇总均值、样本标准差应一致。

公开全部成本

记录所列实验的训练秒数、生成秒数、GPU 小时与 LLM token 总量。不适用的实际成本填写 0，未知值不得填写成 0。

提供可访问的证据

链接到配置、日志与必要产物。数据中的数值不能只靠手填声明，维护者需要核对原始证据。

下载 JSON 模板 ↓下载已收录结果 ↓

未填写模板的 status 为 unmeasured，校验失败是预期行为；它不会被计入结果。当前模板面向可数值化的多轮实验，不代替人工对话质量评价报告。

python3 scripts/validate_result.py path/to/measured-result.json

校验器检查字段、有限数值、种子与轮次、逐 seed 汇总一致性及证据 URL 格式。指标可为负，以保留退化、奖励和估计值；标准差与成本必须非负。具体指标的取值范围仍需人工核对。校验器不会运行实验，也不会自动证明链接中的实验真实。

提交与维护

完成实测后，把验证通过的记录追加到 data/results.json 数组，附上运行配置与可访问的证据，向 GitHub 仓库 提交 Pull Request。构建时会重新校验所有记录；未完成的模板不得放入结果数组。

初始版本不设跨协议总排名。结果应按同一数据版本、切分、候选协议、模型及预算分别比较。
